# Ganesh Hake - Personal Portfolio Website

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript. Features smooth animations, interactive elements, and a clean, professional design.

## 🌟 Features

- **Fully Responsive Design** - Works perfectly on desktop, tablet, and mobile devices
- **Modern UI/UX** - Clean, professional design with smooth animations
- **Interactive Elements** - Hover effects, scroll animations, and dynamic content
- **Skills Showcase** - Animated progress bars and skill categories
- **Contact Form** - JavaScript-powered form with validation (no backend required)
- **Fast Loading** - Optimized for performance
- **SEO Friendly** - Semantic HTML structure

## 💻 Local Development

1. **Clone or download the project files**

2. **Open in browser**
   - Simply open `index.html` in your web browser
   - No build process or server required!

3. **Edit the content**
   - Modify HTML files to update text and content
   - Edit `css/style.css` to customize colors and styles
   - Update `js/script.js` to add/modify functionality

## 🎨 Customization

### Colors
Edit CSS variables in `style.css`:
```css

    --primary-color: #2563eb;
    --secondary-color: #8b5cf6;
    --accent-color: #f59e0b;
    /* ... more colors */
}
```

- **Profile Image**: Replace placeholder in `index.html` (line 67)
- **Personal Info**: Update contact details in `contact.html`
- **Skills**: Modify skill percentages in `about.html`
- **Social Links**: Update URLs in footer sections

## 🌐 Deployment on Vercel

### Method 1: Using Vercel CLI

1. **Install Vercel CLI**
   ```bash
   npm install -g vercel
   ```

2. **Deploy**
   ```bash
   cd portfolio-website
   vercel
   ```

3. **Follow the prompts** and your site will be live!

### Method 2: Using Vercel Dashboard

1. Go to [vercel.com](https://vercel.com)
2. Click "New Project"
3. Import your Git repository or drag & drop your project folder
4. Vercel will automatically detect it as a static site
5. Click "Deploy"

### Method 3: Drag & Drop

1. Zip all project files
2. Go to [vercel.com/new](https://vercel.com/new)
3. Drag and drop your zip file
4. Done! Your site is live
